Plan around the smallest effect that matters, not around an effect reported in an earlier small study. Calculations use t distributions and assume normally distributed outcomes.

SWC = factor × between-athlete SD. SEM = SD × √(1 − ICC). MDC = z × √2 × SEM. Small-telescopes bound: the standardized effect the original study had 33% power to detect (Simonsohn 2015); multiply by the SD of the paired differences (or the pooled SD) for raw units.

Published thresholds for common sports medicine outcomes. Thresholds depend on population, anchor and method, and most are individual-level values: used as a between-group bound they make equivalence easier to declare. Read the source before using one.

How to read the five patterns

PatternWhat it means
Clinically importantThe whole confidence interval is beyond the threshold. The effect is real and large enough to matter.
Real, importance unclearThe interval excludes zero but reaches past the threshold. There is probably an effect, but we cannot tell whether it matters.
Real but trivialThe interval excludes zero but stays inside the threshold. There is probably an effect, but it is too small to matter.
Practically equivalentThe interval includes zero and stays inside the threshold. The options can be treated as the same for patients.
InconclusiveThe interval includes zero and reaches past the threshold. The study cannot tell. This is not evidence of no difference.

By default every judgment uses the 95% CI: zero, clinical importance (one-sided minimum-effect test, alpha = 0.025) and equivalence (two one-sided tests, alpha = 0.025 each, the CONSORT convention for equivalence and non-inferiority trials), so a result equivalent within a bound is always non-inferior at a margin of the same size. Choose alpha = 0.05 per side (the 90% CI) only to match bioequivalence conventions. Standard errors are recovered from the reported limits, so results from published summaries are approximations. With raw data, analyze the data directly (for example with the TOSTER or clinthresh R packages). The threshold must be chosen before looking at the result.
